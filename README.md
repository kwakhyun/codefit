## 예제 앱으로 배우는 개발 기초

코딩 경험이 없어도 **앱의 원리 배우기**에서 시작할 수 있습니다.
메모와 예약 앱으로 실습하며 데이터가 저장되는 과정과 오류를 해결하는 방법을 배웁니다.

- **기초 미션 6개** — 저장 위치, 요청과 응답, 접근 권한, 변수와 조건, 목록, 비동기를 배웁니다.
- **앱 오류 해결 실습 3개** — 메모 저장 실패, 비공개 글의 접근 권한, 중복 예약 문제를 다룹니다.
- **AI에게 요청하는 연습** — 재현 순서, 실제 결과, 기대 결과와 유지할 동작을 정리합니다.
- **수정 결과 확인** — 그럴듯한 수정안을 골라도 정상과 실패 상황 검사를 통과하는지 확인해야 합니다.

예상하기 → 직접 확인 → 수정과 검사 → 다른 상황에 적용하기.
코드는 필요할 때 펼쳐 볼 수 있고, 단계별 힌트와 선택적 AI 질문으로 이어갑니다.

![작은 앱을 조작하며 배우는 입문 미션](docs/images/beginner-observe.png)

[앱의 원리부터 배우기 →](https://codefit-five.vercel.app/learn)

모든 앱은 가상의 데이터로 동작하는 **교육용 모의 환경**입니다. 실제 제품의 서버나 보안을
검사하는 기능은 아닙니다. 작성한 예상, 관찰과 수정 요청은 자동 저장되고 여러 탭의 충돌도
비교할 수 있습니다. 입문 기록은 미션 상단에서 별도 텍스트로 내려받으며 코딩 백업에는
포함되지 않습니다. 입문 기록 가져오기는 지원하지 않습니다. AI 질문 없이도 모든 미션을 마칠 수 있습니다.

## “이 코드, AI 없이도 고칠 수 있을까?”

코드를 읽으면 이해되는데 막상 직접 쓰려면 손이 멈추는 순간이 있습니다.
CODE:FIT은 그런 감각을 다시 깨우기 위해 만들었습니다.
정답을 따라 적는 대신 실제 개발에서 만날 법한 상황을 풀어 봅니다.

- **직접 구현하기** — 요구사항을 읽고, 비어 있는 기능을 완성하세요.
- **오류 고치기** — 예상과 다른 결과의 원인을 찾아 수정하세요.
- **리팩터링하기** — 동작은 지키면서 더 읽기 쉽고 안전한 코드로 바꾸세요.

## AI가 작성한 코드 분석하기

**AI 코드 이해 훈련**은 짧은 코드 하나의 결과를 예상하는 것부터 시작합니다.
프론트엔드와 백엔드의 JavaScript 기본 과제 6개와 변형 과제 6개를 준비했습니다.

1. **예측하기** — 원본을 읽고 결과와 이유를 먼저 남깁니다. 틀린 예상도 그대로 보관합니다.
2. **비교하기** — 원본을 실제로 실행해 내 예상과 비교합니다. 막히면 AI가 한 가지 질문으로 생각할 지점을 짚어 줍니다.
3. **수정하기** — 요구사항에 맞게 고치고 제공된 테스트를 실행합니다. 코드를 바꾸면 이전 결과임을 알려 줍니다.
4. **설명하고 응용하기** — 구조, 판단, 검증과 남은 위험을 내 말로 정리하고 다른 상황의 문제에 도전합니다.

![예상과 실제 실행 결과를 비교하는 코드 이해 훈련](docs/images/understanding-observe.png)

예측, 코드, 실행 기록과 분석 메모는 함께 자동 저장됩니다. 여러 탭에서 내용이 달라져도
초안을 보존하고 비교할 수 있습니다. 이전 제출본 복원, 실행 취소와 문서 내보내기도 지원합니다.

12개 훈련의 코드는 **브라우저의 분리된 QuickJS 환경**에서 실행합니다. 제공된 테스트의 실행 결과와
AI의 정적 검토는 별도로 표시합니다. DOM, 네트워크, 타이머와 외부 모듈은 지원하지 않으며,
테스트 통과나 AI 피드백을 실력 인증으로 표현하지 않습니다. 다른 분야의 일반 문제는 기존 AI 정적 리뷰를 사용합니다.

변형 과제는 바로 연습할 수 있습니다. 최초 기본 검토 7일 뒤의 첫 재도전은 별도 지표로 기록하며,
서비스 내 힌트, 정답 또는 AI 질문을 사용한 풀이와 구분합니다. 서비스 밖의 도움 사용은 확인하지 않습니다.

메인 화면이나 메뉴의 **AI 코드 이해 훈련**에서 시작하세요. 로컬 경로는 `/handoff`입니다.
[설계와 검증 근거](docs/engineering.md#ai-코드-이해-훈련)를 함께 공개합니다.

## 오늘 필요한 만큼, 나에게 맞는 난이도로

프론트엔드, 백엔드, 게임, 네트워크, 데이터베이스, 인프라, 모바일, 데이터/AI,
보안, 시스템까지 **10개 분야와 26개 언어·기술**을 연습할 수 있습니다.

| 하                        | 중                         | 상                          |
| ------------------------- | -------------------------- | --------------------------- |
| 기본 문법과 작은 기능부터 | 실무에서 마주치는 요구사항 | 복잡한 조건과 설계 판단까지 |

분야와 언어, 유형으로 검색하고 북마크해 두세요.
원하는 문제가 없다면 **GPT-5.6 Sol**에 상황을 설명해 새로 만들 수 있습니다.
생성한 문제는 공개 보관함에 계속 쌓여 다른 개발자의 다음 연습이 됩니다.

## 막히더라도, 한 걸음씩 풀어갈 수 있도록

1. **문제를 고르고 직접 작성하세요.** 코드가 자동 저장되어 다음 연습에서도 이어집니다.
2. **필요한 만큼만 도움받으세요.** 단계별 힌트 3개와 참고 정답, 해설을 확인할 수 있습니다.
3. **피드백으로 다시 고쳐 보세요.** AI가 요구사항별 충족 여부와 개선점을 알려 줍니다.
4. **어제의 풀이와 비교하세요.** 이전 제출본을 다시 열고, 도움 없이 해결한 문제와 연속 연습일을 확인하세요.

![문제와 편집기를 함께 보는 CODE:FIT 풀이 화면](docs/images/workspace.png)

검정 터미널 테마, 집중 모드, 글자 크기 조절과 키보드 단축키로 코드에 집중하세요.
[모바일에서도 보관함과 풀이를 확인할 수 있습니다.](docs/images/mobile.png)
연결이 잠시 끊겨도 미저장 코드를 브라우저에 보관하고, 연결이 돌아오면 다시 저장합니다.
다른 탭이나 기기에서도 코드를 고쳤다면 내 초안을 보존한 채 서버 저장본과 비교하고 이어갈 수 있습니다.

## 연습은 누구나. 새 문제는 하루 3개.

| 이용 기능                              |   로그인 없이   | Google / GitHub 로그인 |
| -------------------------------------- | :-------------: | :--------------------: |
| 입문 실습, 모든 문제 풀기, 힌트와 해설 |        ✓        |           ✓            |
| AI 풀이 검토와 맞춤 질문               |        ✓        |           ✓            |
| 자동 저장, 북마크, 학습 기록과 백업    | 이 브라우저에서 |    계정으로 이어서     |
| AI 문제 생성                           |        —        |      **하루 3회**      |
| 개인 프로필과 로그인 계정 연결         |        —        |           ✓            |

생성 횟수는 **한국 시간 자정**에 갱신됩니다. 생성에 실패하면 횟수를 돌려드립니다.
로그인 전 기록은 브라우저의 게스트 연습실에 남습니다. 코딩 기록은 백업을 내보낸 뒤 로그인하고
가져오면 계정으로 이어갈 수 있습니다. 이미 작성한 계정의 코드는 덮어쓰지 않습니다.

AI 풀이 검토는 기본 **GPT-5.6 Luna**가 코드와 요구사항을 읽는 리뷰이며, 코드를 실행하는 채점은 아닙니다.
정확하지 않은 피드백이 있을 수 있어 [검토 방식과 실제 검증 결과](https://codefit-five.vercel.app/quality)를 공개합니다.
AI 풀이 검토와 맞춤 질문은 개인별 24시간 기준 총 20회를 공유하며, 접속망과 서비스 전체의 공용 한도도 적용됩니다.
