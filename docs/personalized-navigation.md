# 작업 공간에 따른 홈과 탐색

작업 공간은 학습 기록과 권한을 바꾸지 않는 브라우저 표시 설정이다. 세 공간 모두 모든 기능에 접근할 수 있지만 홈 구조와 메뉴 순서가 다르다.

| 작업 공간     | 홈 구조                                                                              | 주요 메뉴 순서                                                                    |
| ------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| 서비스 점검실 | 서비스 점검 진입, 최근 프로젝트, 설계 설명에서 검증까지의 절차, 보안 점검, 원리 보충 | 프로젝트 → 보안 → AI 실무 → 코드 이해 → 분야별 코딩 → 서비스 원리                 |
| AI 워크숍     | 내 프로젝트 AI 학습 진입, 학습 현황과 최근 수업, 목적별 학습 경로, 확장 주제         | AI 실무 → 코드 이해 → 프로젝트 → 보안 → 분야별 코딩 → 서비스 원리                 |
| 코딩 트레이닝 | 작성 중 코드, 10개 분야 선택, 코드 이해 훈련, 검색 가능한 문제 목록                  | 분야별 코딩과 분야 바로가기 → 코드 이해 → AI 실무 → 프로젝트 → 보안 → 서비스 원리 |

서비스 점검실과 AI 워크숍은 기존 히어로 안에 공개 저장소 입력창을 통합한다. 서비스 점검실은 점검과 실습, AI 워크숍은 프로젝트 AI 활용 학습으로 연결한다. 코딩 트레이닝은 저장소 입력창 없이 분야별 코딩 문제와 작성 중인 코드부터 보여준다. 공간 선택 전에도 프로젝트 점검 질문 5개와 코드 훈련 3개, 서비스 동작 실습 3개를 함께 준비할 수 있다.

## 선택과 기록

- 첫 방문에는 공개 저장소 입력창 아래에 세 공간의 이미지 카드를 보여준다. 선택 후에는 전용 홈으로 이동하고 헤더의 ‘작업 공간 변경’에서 다시 고른다.
- 라디오 선택은 즉시 반영한다. 첫 선택 후 제목에 초점을 옮기고 대화상자를 닫으면 진입 버튼으로 돌아간다.
- 기존 저장 키 `codefit-learning-preference-v2`를 유지하되 값은 `{ version: 3, type: "service" | "ai" | "code" }`다.
- 기존 원리 입문은 AI 워크숍, 코드 훈련은 코딩 트레이닝, 내 서비스 이해와 배포 전 점검은 서비스 점검실로 옮긴다. 이전 v1 조합도 같은 기준으로 처리한다.
- 선택은 계정과 관계없이 브라우저에 저장한다. 저장 실패 시 메모리에서만 적용하고 안내한다. 다른 탭의 변경은 storage 이벤트로 반영한다.
- AI 워크숍의 진도는 기존 AI 학습 저장소를 읽고, 최근 변경한 미완료 수업을 이어준다. 서비스 점검실은 현재 범위의 프로젝트 기록을 조회한다. 공간 변경으로 학습 기록이나 작성 코드를 수정하지 않는다.
- 처음 공간을 고르기 전에는 전체 기능 배너도 제공한다. 선택 후에는 공간별 홈이 이를 대체한다.

## 이미지

내장 image_gen으로 공간별 이미지를 생성하고 1200×800 WebP로 저장했다. 실제 실행 화면이 아닌 장식용 그림이며 제목과 설명은 HTML로 제공한다. 이미지가 로드되지 않아도 공간을 고를 수 있다.

- `public/images/personas/persona-service.webp`: 파란 서비스 화면, 돋보기, 데이터와 권한 모듈
- `public/images/personas/persona-ai.webp`: 보라색 문서, 워크플로우, 모델과 열린 책
- `public/images/personas/persona-code.webp`: 호박색 코드 화면, 테스트 타일과 키보드

전체 생성 프롬프트는 [제작 기록](design/workspace-visuals.json)에 있다.

## 검증

`src/lib/learning-preference.test.ts`는 기존 선택값 이전, 새 공간 복원, 메뉴 우선순위와 전체 기능 유지 여부를 확인한다. `e2e/learner-types.spec.ts`는 세 홈의 구분, 이미지, 모바일 넘침, 저장소 실패와 코드 초안 보존을 다룬다. 공간 변경은 유료 AI 호출을 실행하지 않는다.

작업 공간 선택창은 카드를 누르면 즉시 적용하고 닫는다. 이미 선택된 카드를 다시 눌러도 닫히며 별도의 완료 버튼은 없다. 모바일 홈 헤더는 메뉴, 로고, 작업 공간 변경과 빠른 작업을 한 줄로 배치한다. AI 문제 생성, 사용 안내와 새로고침은 빠른 작업에서 연다.
