# AI 제안을 실제 비교 실험으로 연결하기

코칭의 ‘다음 확인’이 설명문만 제공하던 흐름에 실험 편집과 실행을 추가했다. 사용자는 AI 제안 코드를 확인하고 가져온 뒤 입력이나 예상 결과를 바꿀 수 있다. AI 없이도 원본 실행식을 시작점으로 직접 실험할 수 있다.

## 제품 동작

1. 첫 예측을 남기고 원본 실행 결과를 확인한다.
2. 비교 화면의 ‘더 살펴보기: AI 질문과 직접 실험 (선택)’을 펼친 뒤 ‘직접 실험해 보기’에서 실행식과 예상 결과를 작성한다. AI 질문을 받은 경우 제안을 펼쳐 확인하고 명시적으로 가져올 수 있다. 가져오기만으로는 실행하지 않는다.
3. ‘두 코드로 실험 실행’을 누르면 원본과 현재 수정 코드에서 같은 표현식을 각각 실행한다. 결과는 나란히 표시하며 통과/실패 점수를 붙이지 않는다. 문법 오류나 끝나지 않는 작업은 실행 오류로 표시한다.
4. 마지막 실행의 입력, 예상, 코드 식별값과 두 결과를 기존 학습 저장에 함께 보관한다. 코드나 실행 조건이 달라졌으면 이전 기록이라고 표시한다. 새 실행은 마지막 결과를 갱신한다.

실행 자체는 추가 AI 호출을 만들지 않는다. 원본·수정 코드는 각각 새 Worker와 QuickJS 런타임에서 실행되며 서로의 전역 변수나 변이된 입력을 공유하지 않는다. 한쪽 함수에 오류가 있어도 다른 쪽 결과를 볼 수 있다. 기존 VM 실행당 600ms, 힙 16MiB, 결과 1,600자 제한을 사용하고, 각 Worker는 최대 12초 후 종료된다. 네트워크, DOM, 타이머, 호스트 파일 접근은 제공하지 않는다. 사용자 코드와 AI 제안 표현식을 서버에서 실행하지 않는다.

## 저장과 비동기 작업

실험 코드 최대 2,000자와 예상 최대 800자를 기존 V2 훈련 봉투에 넣는다. 이 봉투는 코드와 함께 리비전 기반 저장, 로컬 복구, 백업과 내보내기의 보호를 받는다. 전체 코드·메모·훈련 기록의 30,000자 제한은 유지한다. 결과는 실행 당시 식별값과 표현식을 포함하므로 현재 조건과의 차이를 표시할 수 있다.

실행 중 코드나 메모를 편집하면 새 입력을 보존하면서 이전 코드의 결과로 표시한다. 실행식이나 예상 자체가 바뀌면 늦게 도착한 결과를 붙이지 않는다. 취소는 Worker를 종료하고 작성 내용과 기존 결과를 보존한다. 계정이나 문제 전환 시 기존 컴포넌트의 작업도 중단한다.

보관된 예전 AI 질문은 `experiment`가 없어도 읽을 수 있다. 새 모델 응답은 완결된 `experiment.expression`을 필수로 받는다. 같은 완료 요청을 다시 조회하면 실험 코드까지 그대로 반환하며 추가 AI 호출이나 이용 한도 소비가 없다. 모델은 대상 함수를 다시 구현하지 않고 함수 호출, 테스트 입력 준비와 관찰 결과만 작성하도록 지시받는다. 구조 검증만으로 이 지침 준수를 보장하지는 않는다.

## 실제 모델과 실행 검증 — 2026-09-20

최종 프롬프트 `2026-09-20.coach.3`, Luna로 합성 사례 **16개를 각각 1회** 호출했다. 기존 진단 8개와 호출 전에 작성한 추가 사례 8개를 분리했다. 추가 사례는 얕은 복사, 무조건 publish, 문자열 Boolean 변환, await 후 캐시, 문자열 페이지 변환, 기존 정상 합계, 문법이 미완성인 수정 코드와 아무 변경도 하지 않는 수정 코드다.

생성된 표현식은 모두 대상 함수를 호출하고 필요한 입력과 변수를 자체 준비했다. 32회의 QuickJS 실행 중 **31회는 값을 반환했고, 1회는 의도한 미완성 코드의 문법 오류**를 그대로 반환했다. AI가 수정 코드를 완성하거나 정답 함수로 교체하지 않았다. 오류를 숨긴 통과 판정은 만들지 않는다. 예외 후 재시도와 없는 `cancelled` 필드의 JSON 표현도 실제 실행으로 확인했다.

기술적으로 실행됐다는 사실과 적절한 코칭은 별개다. 문자열 페이지 입력을 안전하다고 주장한 사례에서는 AI가 그 오해를 다루지 않고 빈 배열만 실험했다. 원본과 맞지 않는 클라이언트 결과를 넣은 진단은 질문 표현이 여전히 매끄럽지 않았다. 이 입력은 실제 HTTP API에서는 이전에 추가한 검증으로 유료 호출 전에 거절된다.

이번 유료 호출의 총 추정 토큰 비용은 **$0.015289**다. 실제 청구액은 아니다. [원문 연결과 사례별 검토](../reports/learning-experiments.json)에 입력, 응답, 실제 실행 결과, 중간 확인과 한계를 보관했다. 공개 문항을 활용해 개발 에이전트가 검토한 진단이며, 독립 평가자의 정확도 측정이나 실제 사용자의 학습 전이 연구가 아니다.

## 재현

```sh
npx vitest run src/lib/handoff/experiment.test.ts src/lib/handoff/training.test.ts src/lib/server/ai-coach.test.ts src/lib/server/understanding-coach-route.test.ts
npx playwright test e2e/learning-experiment.spec.ts
node --env-file=.env.local --import tsx scripts/evaluate-understanding-coach.ts --live
node --env-file=.env.local --import tsx scripts/evaluate-understanding-coach.ts --live --suite transfer
```

마지막 두 명령은 각각 유료 8회다. `--live`를 생략하면 사례 계획만 출력한다. 브라우저 검증의 AI 응답은 모의 데이터이며 실제 Worker/WASM 실행은 사용한다. 전체 테스트와 운영 배포는 이 작업에 포함하지 않는다.

사용자가 실험을 상수 반환으로 바꾸거나 AI가 적절하지 않은 입력을 고를 수 있다. 표시된 값은 해당 코드와 표현식의 관찰이며 이해도 인증이나 임의의 모든 입력에 대한 정답 보장이 아니다. 표현식 자체의 의미, 질문의 적합성, 실험 후 설명의 향상을 평가하는 근거가 추가로 필요하다.
