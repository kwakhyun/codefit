# 공개 프로젝트 화면 수집

프로젝트 점검은 Vercel Sandbox의 일회용 Chromium에서 자바스크립트를 실행한다. 새 브라우저 프로필에는 코드핏 세션, API 키, DB 인증을 전달하지 않는다. 최대 3개 공개 HTTPS 페이지의 본문과 상단 스크린샷을 OpenAI 질문 생성에 사용한다. 화면에 표시된 내용은 한 시점의 관찰이며 실제 서버 구현이나 오류 재현의 증거로 취급하지 않는다.

수집기는 스크롤과 HTML `details` 펼치기만 수행한다. 폼 제출, 로그인, 임의 버튼 클릭, 소스 저장소 조회는 하지 않는다. 같은 출처의 공개 링크를 제한적으로 따라가며 로그인, 생성, 수정, 삭제, 다운로드와 결제 경로는 제외한다. 하위 iframe, 서비스 워커, 웹소켓, GET/HEAD 외의 요청은 차단한다. 이 제한 때문에 일부 서비스의 본문을 읽지 못할 수 있다.

전체 수집은 40초, VM 수명은 45초로 제한한다. 수집 코드의 탐색 시간은 약 26초이며 페이지당 본문 10,000자와 200 KB 이하 JPEG 한 장을 보관한다. VM 방화벽으로 사설 IPv4 대역을 차단하고 IPv6는 실행 전에 비활성화한다. 자바스크립트 수집 실패 시 기존 DNS 검증 HTML 수집으로 전환하며, UI와 AI 입력에 실제 화면 표시 여부가 미확인임을 명시한다.

## 브라우저 이미지 준비

프로젝트 범위의 Vercel OIDC 인증이 준비된 환경에서 실행한다.

```sh
node --env-file=.env.local scripts/create-project-browser-snapshot.mjs
```

출력된 `PROJECT_BROWSER_SNAPSHOT_ID`를 로컬 환경과 사용하는 Vercel 배포 환경에 등록한다. 운영 런타임은 Vercel의 단기 OIDC 인증을 사용한다. 스냅샷에는 Chromium, Playwright와 한글 글꼴만 설치하며 프로젝트 코드와 비밀정보는 넣지 않는다. 만료 없는 이미지를 생성하므로 교체 후 사용하지 않는 이전 이미지는 별도로 정리해야 한다. 패키지는 Playwright 1.63.0으로 고정했다.

이미지 식별자가 없거나 인증, 수집이 실패하면 HTML 방식으로 전환한다. 배포 이후 정상 경로 여부는 새 점검의 `page.source`가 `rendered`이고 캡처 목록이 존재하는지로 확인할 수 있다. 기존 점검은 자동으로 다시 분석하지 않는다.

## 기록과 확인

스크린샷은 계정의 분석 기록에 저장하며 목록 응답에는 이미지와 본문을 포함하지 않는다. 이미지 조회 API는 로그인과 workspace 일치를 검사하고 소유자의 기록만 조회한다. 응답은 `private, no-store`이다. 질문 생성에는 이미지를 별도 `input_image`로 전달하고, 답변 평가에는 보내지 않는다.

기록 삭제와 백업은 기존 프로젝트 기록 정책을 따른다. 백업에는 이미지도 포함되므로 기존 4 MB 한도에 유의한다. 자기 프로젝트 확인 과제와 보완 답변에 관한 흐름은 [프로젝트 학습](project-learning.md)에 설명했다.
