# 비교 실험 뒤의 설명과 후속 질문

추가 실험은 실행 결과를 보관했지만 AI 코칭은 최초 예측과 원본 관찰만 읽었다. 이제 실험 결과를 보고 알게 된 점을 작성한 뒤, 그 설명과 두 코드의 결과를 바탕으로 다음 질문을 받을 수 있다.

## 학습 흐름

1. 원본과 수정 중인 코드에서 같은 실험을 실행한다.
2. 예상과 실제 결과를 비교해 `실험 후 알게 된 점`을 적는다. 최초 예측은 그대로 남고 새 설명을 별도로 저장한다. AI 연결 없이도 작성·저장할 수 있다.
3. `실험 결과로 다음 AI 질문 받기`를 명시적으로 누른다. 기존 AI 이용 한도를 사용하며, 실험 실행이나 설명 편집 자체는 AI를 호출하지 않는다.
4. AI는 새 설명의 원문을 인용하고 다음 질문과 실행식을 제안한다. 올바르게 수정된 설명은 이전의 오해로 취급하지 않는다. 남은 오해가 있으면 해당 주장을 확인하고, 충분히 설명한 내용은 새로운 경계 조건으로 확장한다.

## 기록 일치와 요청 보호

- 설명은 실행식, 실행 당시 예상, 원본 출처, 수정 코드, 실행기 버전과 두 결과를 묶은 SHA-256 식별값에 연결한다. 결과가 바뀌면 이전 설명을 보존하고, 현재 결과에 맞게 수정하거나 같은 설명을 사용할지 확인하게 한다.
- 코드·실행 조건·예상이 달라진 경우 현재 실험을 다시 실행해야 후속 질문을 요청할 수 있다. 서버에서도 같은 조건을 검사하며, 누락·오래된 설명과 잘못된 결과 형식은 작업 생성·한도 소비·유료 호출 전에 거절한다.
- 예측 코칭과 실험 코칭은 요청 지문을 구분한다. 같은 내용의 실패 재시도는 같은 요청 ID를 사용한다. 이미 완료된 요청은 저장된 결과를 반환하며 추가 AI 호출이나 한도 소비를 하지 않는다.
- 응답 대기 중 새 설명이나 실험 기록이 들어오면 이전 응답을 붙이지 않는다. 새로운 코드 편집은 보존하고, 요청 당시 코드와 다르면 질문 옆에 안내한다.
- 새 질문의 인용문은 **실험 후 설명**에서만 가져올 수 있다. 최초 예측의 설명을 새 설명처럼 인용하면 서버가 거절한다. 저장·새로고침·문서 내보내기에 새 설명과 연결된 실험 식별값을 포함하며, 필드가 없는 옛 기록도 읽을 수 있다.

## 검증의 범위

현재의 원본과 고정된 관찰 결과가 맞는지 확인하는 기존 사전 검사를 유지한다. 추가 실험은 사용자가 작성할 수 있으므로 서버에서 그 결과를 독립적으로 재실행하지 않는다. 두 결과와 해시는 클라이언트가 바꿀 수 있으며, **해시 일치는 실행 사실이나 정답의 증명이 아니다.** AI에는 각 코드의 결과를 구분된 클라이언트 보고로 전달한다. 오류는 실험 준비나 함수 동작을 살펴볼 단서이며 통과/실패 성적이 아니다.

실제 모델 검증은 수정된 이해, 남은 과잉 일반화, 비동기 재시도·해제, 입력 검증, 실험 준비 오류, 결과 문자열의 지시문, 의도적으로 바꾼 결과 보고를 포함한 합성 사례 8개를 사용했다. 같은 사례를 세 단계에서 반복하고 인용 오류 1건을 별도 재시도해 **25회 호출**, 추정 토큰 비용 **$0.02604484**가 들었다. 최종 최초 응답은 **7/8 수용**, 원문에 없는 인용 1건은 거절 후 같은 프롬프트로 재시도해 수용됐다. 수용된 최종 응답 8개의 다음 실험 16회는 모두 값을 반환했고 추가 비용 없는 재실행에서도 일치했다. 최초 호출 8/8 성공으로 표현하지 않는다.

중간 단계의 내부 필드명 노출과 함수 반환값/실험 호출 횟수 혼동도 보존했다. 관련 단위 검사 73개와 브라우저 검사 18개가 통과했다. 같은 사례를 표현 개선 전후로 반복한 개발자 진단이며, 독립 평가나 보지 않은 평가셋이 아니다. 자세한 호출·실행 수와 검토는 [검증 보고서](../reports/experiment-followup-reliability.json)에 기록했다.

```sh
# 계획만 출력, API 호출 없음
node --import tsx scripts/evaluate-experiment-followup.ts

# 교육용 예제와 합성 설명 8개를 OpenAI API로 전송하는 유료 검증
node --env-file=.env.local --import tsx scripts/evaluate-experiment-followup.ts --live
```

이 실행은 운영 DB나 실제 사용자 제출 코드를 읽지 않는다. API 키는 인증에만 사용하며 출력하거나 보고서에 저장하지 않는다. 전송 대상은 OpenAI API origin으로 제한한다. 최초 자동 승인 검토가 외부 전송을 거절한 뒤 사용자가 해당 데이터와 목적지를 명시 승인했고, 이후 실제 호출을 실행했다.

실제 학습자의 이해 개선, 장기 기억, 경쟁 제품 대비 우위는 아직 측정하지 않았다. 후속 질문의 실행 성공이나 개발 에이전트의 정성 검토를 SOTA 달성 근거로 해석하지 않는다.
