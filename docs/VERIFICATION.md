- 운영 환경에서 접근 암호 로그인, 이전 문제 조회, 실제 AI 문제 생성과 오류 코드 검토, 초안 저장/재조회, 힌트와 정답 공개를 확인. 생성된 문제는 보관함에 유지함.
- 운영 런타임 오류 조회 결과 오류 없음.
- Next.js 16.3의 standalone/플랫폼 어댑터 충돌을 피하도록 Vercel에서는 기본 출력 방식을 사용하고 로컬/Docker에서는 standalone을 유지함.
- GitHub 비공개 저장소 `kwakhyun/codefit`과 Vercel `codefit`의 Git 연동 완료. `main` 푸시는 운영 배포 대상.
- GitHub Actions에서 실제 PostgreSQL 서비스를 사용한 테스트 27개, 린트와 프로덕션 빌드 통과.
- 운영용 `codefit-db`와 미리보기용 `codefit-preview-db`를 분리하고 암호화된 환경변수를 등록함.
- 승인받은 로컬 문제 13개를 운영 DB로 이전. 기본 문제 12개는 중복 생성하지 않고 AI 문제 1개, 진행 기록 1개와 제출 기록 3개를 추가함.
- 미리보기 DB에서 프로덕션 API 통합 검증 통과. 사용자별 격리, 코드 저장, 힌트/정답과 백업 복원을 확인함.
- Neon 연결이 테스트용 search_path 설정을 적용하지 않는 사례를 발견. 테스트가 public 영역에 기록하기 전에 중단하도록 current_schema 확인을 추가함. CI는 별도의 PostgreSQL 서비스에서 전체 테스트를 실행함.
- 기존 테스트용 중복 문제와 alice/restored 기록은 운영 DB 삭제 승인 검토에서 차단되어 보존 중. 실제 사용자 기록과 구분되며 서비스 기능에는 영향 없음.
- 개인 기록은 브라우저 세션에 연결됨. 로컬과 배포 도메인의 쿠키가 다르므로 로컬 기록을 배포 화면에서 이어가려면 JSON 백업 가져오기를 사용함.

## 운영 범위

- 운영 서비스는 공유 접근 암호로 보호함. 암호와 API 키, 데이터베이스 주소는 Git에 포함하지 않음. 로컬 서버는 종료함.
- Dockerfile을 제공하며 Docker 엔진을 통한 이미지 빌드/배포는 별도로 수행하지 않음.
- AI 검토는 정적 리뷰. 사용자 코드를 실행하거나 컴파일하는 샌드박스는 포함하지 않음.
- 로컬은 SQLite, Vercel은 Neon PostgreSQL에 영구 저장함. 이메일 계정과 기기 간 자동 동기화는 별도 확장 대상.
- 생성 가능한 언어는 26개이며 모든 언어 조합에 실제 AI 호출을 반복하는 검증은 수행하지 않음. 선택 가능 조합과 생성 입력의 구조는 검증함.
