# 검증 기록

## OAuth와 생성 한도 — 2026-09-13

- 실제 PostgreSQL을 포함한 49개 자동 테스트 통과. SQLite/PostgreSQL 공통 계약, OAuth 콜백과 상태 변조, 서명된 세션, 프로필 변경과 로그아웃을 확인했습니다.
- 동시 요청에서도 계정별 하루 3회 제한을 유지하며, 실패한 생성의 예약 반환, 만료된 예약, 멱등 재요청, 한국 시간 자정 갱신을 검증했습니다.
- 문제 생성 모델 `gpt-5.6-sol`의 API 접근 가능 여부를 확인했습니다. 풀이 검토는 `gpt-5.4-mini`를 사용합니다.
- 브라우저 시나리오 10개 통과. 비회원 생성/프로필 차단, 비회원 AI 검토 접근, 프로필 저장과 모바일 접근성, 생성 한도 표시, 로그아웃, 계정 전환 중 저장과 프로필 격리를 확인했습니다.
- 실제 AI 요청 2회로 생성과 검토, 영구 저장, 동일 요청 재시도 시 중복 호출 방지, 생성 잔여량 2회 반영을 확인했습니다. 테스트 문제는 임시 로컬 DB에만 저장했습니다.
- 서식, ESLint, TypeScript, 미사용 코드 검사와 프로덕션 빌드, 별도 API 통합 검증을 통과했습니다.
- Google OAuth 앱을 외부 사용자 대상 프로덕션으로 게시하고 GitHub/Google 비밀키를 Vercel 서버 전용 환경 변수에 설정했습니다. 실제 제공자 콜백은 운영 배포 후 확인합니다.

## 기존에 검증한 서비스 기능

- 비회원 공개 접속, 검색과 URL 조건 복원, 지연된 검색 응답 처리, 코드 자동 저장과 오프라인 복구, 사용자별 기록 격리, 힌트와 정답, 제출본 복원, 백업 가져오기.
- 데스크톱과 390px 모바일의 탐색과 편집기, 가로 넘침, 주요 화면의 자동 접근성 검사.
- 문제, 진행 기록, 제출 결과의 영구 저장과 SQLite/PostgreSQL 호환. 운영과 Preview의 데이터베이스 분리.
- 검정 배경과 회색 패널을 기본으로, 동작과 상태에 맞춘 강조색을 사용합니다.

AI 검토 평가와 응답 시간, 저장소 벤치마크는 [설계와 측정 결과](engineering.md), 재현 절차는 [개발 안내](development.md)에 정리했습니다. 이전 공유 암호 방식은 제거했으며 저장소와 문제 풀이는 공개 상태입니다.

## 검증 범위와 한계

AI 검토는 정적 피드백이며 제출 코드를 실행하거나 컴파일하지 않습니다. 선택 가능한 26개 언어의 모든 조합에 유료 AI 호출을 반복하지는 않았습니다. 일반 테스트와 CI는 유료 API를 호출하지 않습니다. Docker 이미지의 실제 실행은 별도로 검증하지 않았습니다. 화면과 테스트용 데이터는 Git에서 제외한 `artifacts/`에 저장합니다.
