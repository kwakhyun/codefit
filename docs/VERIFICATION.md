## 운영 범위

- 운영 서비스는 공유 접근 암호로 보호함. 암호와 API 키, 데이터베이스 주소는 Git에 포함하지 않음. 로컬 서버는 종료함.
- Dockerfile을 제공하며 Docker 엔진을 통한 이미지 빌드/배포는 별도로 수행하지 않음.
- AI 검토는 정적 리뷰. 사용자 코드를 실행하거나 컴파일하는 샌드박스는 포함하지 않음.
- 로컬은 SQLite, Vercel은 Neon PostgreSQL에 영구 저장함. 이메일 계정과 기기 간 자동 동기화는 별도 확장 대상.
- 생성 가능한 언어는 26개이며 모든 언어 조합에 실제 AI 호출을 반복하는 검증은 수행하지 않음. 선택 가능 조합과 생성 입력의 구조는 검증함.
