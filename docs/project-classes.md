# 내 프로젝트

`/projects`는 분석을 마친 프로젝트를 모아 관리하는 화면이다. 별도의 저장 버튼 없이 기존 분석도 목록에 표시된다. 웹사이트 분석은 점검 질문을 제공하고, 저장소 분석은 코드 이해 훈련, 서비스 동작 실습과 내 프로젝트 AI 워크숍으로 연결한다. 화면에서는 분석해 저장한 대상 하나를 ‘프로젝트’라고 부른다([화면 용어 기준](ui-system.md)). AI 생성이 끝난 과정은 추가 호출 없이 열 수 있다.

## 관리와 복습

- 프로젝트 이름과 학습 목표를 수정한다. 이름을 바꾸면 `/projects`, `/project-check` 기록 목록과 제목, `/project-practice` 저장소 선택, 분석 이력에 같은 이름(`displayName`: 바꾼 이름 → 분석 제목 → 저장소 이름)이 표시된다. 분석 당시 코드, 질문, 답변은 변경하지 않는다. 다른 탭에서 수정했으면 충돌을 알리고 다시 불러오게 한다.
- 다른 탭에서 돌아오면 목록의 첫 페이지를 갱신하면서 검색어와 이미 펼친 목록을 유지한다. 검색어는 계정별 sessionStorage에 보관해 상세 화면에서 목록으로 돌아와도 복원한다. 상세 화면도 최신 진도를 반영하며 편집 중인 이름과 메모는 유지한다. 편집 시작 시점의 리비전으로 충돌을 검사한다.
- 상세 화면에서 과정별 진도와 이어하기 링크를 제공한다. 준비하지 않은 과정은 생성 화면으로 이동하며 기존 사용량 정책을 따른다. 프로젝트 점검 과정은 평가 결과가 저장되면 완료로 계산한다(답변한 질문 수가 아니다). 완료된 과정은 ‘다음 학습’으로 추천하지 않는다.
- 진행 중인 분석은 목록에 ‘분석 중’ 카드로 표시한다. 응답을 받지 못해 상태 조회가 멈춘 분석은 회전 표시 없이 ‘연결 끊김’으로 표시하고 ‘분석 상태 다시 확인’ 한 가지 동작만 제공한다. 이 확인은 상태 조회만 하며 AI를 다시 호출하지 않는다.
- 복습은 설계 질문의 이전 답변과 생성된 확인 문제를 다시 살펴보되 기존 제출 결과는 바꾸지 않는 흐름이다. 객관식 정답과 해설은 선택 후 표시한다. 정답을 보지 않고 ‘건너뛰고 다음’으로 넘어갈 수 있다. 복습 모드는 주소(`/projects?class=<id>&view=review`)에 반영되어 뒤로 가기, 새로고침과 링크 공유에서 유지된다. ‘복습 기록을 비우고 다시 시작’은 확인 대화상자를 거친다. 복습 위치, 문제별 메모, 선택과 해설 공개 상태는 계정과 클래스별로 구분해 이 브라우저의 localStorage에 보관한다. 화면을 나가거나 새로고침해도 이어서 복습할 수 있다. 다른 기기 동기화와 서버 백업에는 포함하지 않는다. 기존 답변과 학습 진도를 덮어쓰지 않으며 브라우저 저장 실패 시 안내한다. Web Locks로 탭 간 저장을 직렬화하고 저장 직전에 최신 기록과 병합한다. 같은 문제의 메모가 충돌하면 다른 탭의 메모도 별도로 보관해 표시한다. 잠금이나 브라우저 저장을 사용할 수 없으면 미저장 상태를 안내한다. 실패한 변경은 화면의 대기 목록에 보존하고 다음 저장에 함께 재시도한다. 저장에 성공한 변경만 대기 목록에서 제거하므로 같은 복습 화면 안에서 다른 문제로 이동해도 미저장 메모를 유지한다. 이 대기 목록은 메모리에만 있어 저장에 성공하기 전에 새로고침하거나 화면을 닫으면 미저장 변경은 복구할 수 없다. AI 호출은 없다.
- 보완 답변은 원래 분석의 클래스에 속한다. 목록과 분석 이력에 별도 프로젝트로 표시하지 않고 원래 프로젝트 화면에서 연다. 코드 이해 훈련, 서비스 동작 실습, 내 프로젝트 AI 워크숍과 기초 개념 연습은 원래 분석의 기록을 그대로 사용해 다시 생성하지 않는다. 보완은 원래 분석당 합계 3번까지 가능하다.
- 삭제 전 프로젝트와 함께 지워지는 기록을 확인한다. `/projects`와 `/project-check`는 같은 확인 대화상자(제목 ‘프로젝트 삭제’, 삭제 항목 목록, ‘프로젝트 영구 삭제’ 버튼)를 사용한다. 분석과 질문, 답변·평가·보완 답변, 확인 기록과 코드 대화, 코드 이해 훈련과 서비스 동작 실습, AI 워크숍과 중간 생성 단계가 함께 삭제되며 실제 저장소와 서비스에는 영향을 주지 않는다. `/project-check`에서는 보완 답변 화면에서 삭제해도 원래 프로젝트 전체를 삭제한다. 어느 화면에서 삭제해도 이 브라우저에 남은 답변 초안, 복습 기록, 선택 상태와 분석 알림을 함께 정리한다.
- 다시 점검하면 별도 프로젝트를 만든다. 기존 프로젝트는 그대로 유지한다. 저장소는 최신 코드로, 웹사이트는 같은 주소의 현재 공개 화면으로 다시 분석하며 분석 횟수 1회 사용과 남은 횟수, 초기화 시각을 버튼 앞에 표시한다. 같은 저장소 주소의 분석 기록을 날짜와 함께 연결하며, 주소 끝의 슬래시와 .git 표기는 같은 주소로 취급한다. 탭 복귀와 백업 가져오기 후 이력의 기존 조회 범위를 갱신한다. 다른 브랜치 경로나 별칭 주소까지 합치지는 않는다. 버전 간 차이를 자동 비교하거나 기존 진도를 새 코드에 이관하지는 않는다.

## 소유권과 데이터

방문자는 기존 쿠키에 연결된 기록, 로그인 사용자는 해당 계정 기록만 접근할 수 있다. 로그인했다고 방문자 기록이 자동으로 합쳐지지는 않는다. 필요한 기록은 기존 백업 기능을 사용할 수 있다.

목록은 기존 `/api/project-check`의 페이지 단위 요약을 사용한다. SQLite와 PostgreSQL에서 필요한 JSON 필드만 조회해 원본 코드와 전체 평가 결과를 목록 응답 처리로 가져오지 않는다. 더 보기는 다음 페이지만 요청한다. 탭 복귀(연속 이벤트는 0.4초 안에 한 번으로 합친다), 백업 가져오기와 분석 완료 시에는 첫 페이지만 다시 읽고, 이미 펼친 이후 페이지는 유지한다. `/project-check`, `/projects`, `/project-practice`가 같은 목록 훅(`useProjectOverview`)을 사용한다. 코드와 상세 학습은 선택할 때 `/api/projects/[id]`에서 불러온다. 이름, 목표와 주소 검색은 소유자의 전체 프로젝트를 대상으로 데이터베이스에서 수행한다. 검색 결과에도 페이지 단위 조회를 적용하며 검색어 변경 시 이전 요청을 취소한다. 검색어는 최대 200자이고 SQL 와일드카드 문자도 일반 문자로 취급한다.

프로젝트 메타데이터(`classMetadata`)는 원본 분석의 `classMetadata`에 이름, 목표, 수정 시각과 리비전을 보관한다. PATCH는 소유권과 리비전을 확인하고 원본 JSON을 비교하는 조건부 갱신을 사용한다. 학습 목표는 프로젝트 관리용 메모이며, 이미 생성한 질문이나 새 생성 요청의 조건을 자동 변경하지 않는다. 기존 분석에는 이 필드가 없어도 동작한다. 개인 백업에 메타데이터를 포함하며 복원 시 검증한다.

## 생성 복구

실습과 AI 워크숍 GET의 `stepwise` 조회는 최종 결과, 완료된 단계 수와 무료 복구 가능 여부를 반환한다. 두 단계가 저장됐지만 마지막 결과 저장이 실패했다면, 남은 횟수 또는 AI 연결 상태와 관계없이 저장된 데이터로 결과를 복구한다. 아직 생성하지 않은 단계에는 기존 한도와 AI 연결이 필요하다.

서비스 실습 생성에는 먼저 만든 코드 실습의 제목, 상황, 질문을 전달한다. 다른 조건과 의사결정을 다루도록 요청하고 완전히 같은 질문은 거부한다. 의미상 유사한 사례까지 자동 판정해 제거하는 것은 아니다.

## 검증 범위

소유권, 동시 수정 충돌, 기존 데이터 보존, 백업 복원과 삭제는 저장소 및 API 테스트로 확인한다. 모바일 390px와 데스크톱 1280px 브라우저 테스트는 프로젝트 정보 수정 후 새로고침, 읽기 전용 복습, 삭제 취소와 확정, 화면 넘침과 접근성을 검사한다. AI 결과의 교육 효과나 보안 수준을 인증하는 기능은 아니다.

## 저장 위치별 차이

| 기록                                                                  | 저장 위치                         | 다른 기기에서 이어가기    | 사용자 JSON 백업 |
| --------------------------------------------------------------------- | --------------------------------- | ------------------------- | ---------------- |
| 완료된 분석, 프로젝트 이름과 목표, 제출 답변, 저장한 실습과 AI 워크숍 | 서버의 소유자별 기록              | 같은 로그인 계정에서 가능 | 포함             |
| 복습 위치, 문제별 메모·선택·충돌 메모                                 | 현재 브라우저 localStorage        | 불가                      | 제외             |
| 목록 검색어                                                           | 현재 탭의 소유자별 sessionStorage | 불가                      | 제외             |
| 저장에 실패해 재시도를 기다리는 복습 변경                             | 현재 화면 메모리                  | 불가                      | 제외             |

게스트 서버 기록은 해당 브라우저 쿠키로 찾는다. 백업의 상세 범위는 [학습 기록 백업](workspace-backup.md)을 따른다. 검색 결과는 전체 서버 기록을 대상으로 하지만, 현재 화면에 펼친 검색 결과 페이지 수까지 다른 기기나 새 탭에 보관하는 것은 아니다.
