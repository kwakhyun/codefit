# 내 프로젝트 학습 클래스

`/projects`는 분석을 마친 프로젝트를 모아 관리하는 화면이다. 별도의 저장 버튼 없이 기존 분석도 목록에 표시된다. 웹사이트 분석은 점검 질문을 제공하고, 저장소 분석은 코드 이해 훈련, 서비스 동작 실습과 AI 활용 학습으로 연결한다. AI 생성이 끝난 과정은 추가 호출 없이 열 수 있다.

## 관리와 복습

- 클래스 이름과 학습 목표를 수정한다. 분석 당시 코드, 질문, 답변은 변경하지 않는다. 다른 탭에서 수정했으면 충돌을 알리고 다시 불러오게 한다.
- 다른 탭에서 돌아오면 이미 불러온 목록을 갱신하면서 검색어와 불러온 페이지 범위를 유지한다. 상세 화면도 최신 진도를 반영하며 편집 중인 이름과 메모는 유지한다. 편집 시작 시점의 리비전으로 충돌을 검사한다.
- 상세 화면에서 과정별 진도와 이어하기 링크를 제공한다. 준비하지 않은 과정은 생성 화면으로 이동하며 기존 사용량 정책을 따른다.
- 복습은 설계 질문의 이전 답변과 생성된 확인 문제를 다시 살펴보는 읽기 전용 흐름이다. 객관식 정답과 해설은 선택 후 표시한다. 복습 위치, 문제별 메모, 선택과 해설 공개 상태는 계정과 클래스별로 구분해 이 브라우저의 localStorage에 보관한다. 화면을 나가거나 새로고침해도 이어서 복습할 수 있다. 다른 기기 동기화와 서버 백업에는 포함하지 않는다. 기존 답변과 학습 진도를 덮어쓰지 않으며 브라우저 저장 실패 시 안내한다. AI 호출은 없다.
- 삭제 전 클래스와 함께 지워지는 기록을 확인한다. 분석, 평가, 실습, AI 학습, 중간 생성 단계가 함께 삭제되며 실제 저장소에는 영향을 주지 않는다.
- 최신 코드 분석은 별도 클래스를 만든다. 기존 클래스는 그대로 유지한다. 같은 저장소 주소의 분석 기록을 날짜와 함께 연결하며, 주소 끝의 슬래시와 .git 표기는 같은 주소로 취급한다. 다른 브랜치 경로나 별칭 주소까지 합치지는 않는다. 버전 간 차이를 자동 비교하거나 기존 진도를 새 코드에 이관하지는 않는다.

## 소유권과 데이터

방문자는 기존 쿠키에 연결된 기록, 로그인 사용자는 해당 계정 기록만 접근할 수 있다. 로그인했다고 방문자 기록이 자동으로 합쳐지지는 않는다. 필요한 기록은 기존 백업 기능을 사용할 수 있다.

목록은 기존 `/api/project-check`의 페이지 단위 요약을 사용한다. SQLite와 PostgreSQL에서 필요한 JSON 필드만 조회해 원본 코드와 전체 평가 결과를 목록 응답 처리로 가져오지 않는다. 더 보기는 다음 페이지만 요청하며 탭 복귀 갱신은 기존에 불러온 범위를 다시 확인한다. 코드와 상세 학습은 선택할 때 `/api/projects/[id]`에서 불러온다. 이름과 목표 검색은 현재 불러온 목록을 대상으로 하며 더 오래된 기록은 추가로 불러올 수 있다.

클래스 메타데이터는 원본 분석의 `classMetadata`에 이름, 목표, 수정 시각과 리비전을 보관한다. PATCH는 소유권과 리비전을 확인하고 원본 JSON을 비교하는 조건부 갱신을 사용한다. 기존 분석에는 이 필드가 없어도 동작한다. 개인 백업에 메타데이터를 포함하며 복원 시 검증한다.

## 생성 복구

실습과 AI 학습 GET의 `stepwise` 조회는 최종 결과, 완료된 단계 수와 무료 복구 가능 여부를 반환한다. 두 단계가 저장됐지만 마지막 결과 저장이 실패했다면, 남은 횟수 또는 AI 연결 상태와 관계없이 저장된 데이터로 결과를 복구한다. 아직 생성하지 않은 단계에는 기존 한도와 AI 연결이 필요하다.

서비스 실습 생성에는 먼저 만든 코드 실습의 제목, 상황, 질문을 전달한다. 다른 조건과 의사결정을 다루도록 요청하고 완전히 같은 질문은 거부한다. 의미상 유사한 사례까지 자동 판정해 제거하는 것은 아니다.

## 검증 범위

소유권, 동시 수정 충돌, 기존 데이터 보존, 백업 복원과 삭제는 저장소 및 API 테스트로 확인한다. 모바일 390px와 데스크톱 1280px 브라우저 테스트는 클래스 수정 후 새로고침, 읽기 전용 복습, 삭제 취소와 확정, 화면 넘침과 접근성을 검사한다. AI 결과의 교육 효과나 보안 수준을 인증하는 기능은 아니다.
