# Jev 코드 읽기 추천

Jev는 프로젝트 점검 결과의 **먼저 살펴볼 코드**에만 사용한다. 저장, 접근 권한, 실패 처리, 외부 연결과 핵심 규칙에 관련된 공개 코드 구간을 추천한다. 제목은 서버가 정한 한국어 문구이며, 파일과 줄 인용은 수집한 원본에서 복원한다. 사용자는 추천 항목을 펼쳐 코드와 원본 링크를 확인할 수 있다.

## 유지한 기능과 제거한 실험

- 유지: 코드 구간별 실행 로직 유무(Noul)와 역할(Choice)을 같은 요청에서 독립적으로 판단해 읽기 후보를 고른다. 새 저장소 분석 결과에 저장되며 기록을 다시 열 때 재호출하지 않는다. 기존 기록에 자동으로 추가하지 않으며 공개 웹사이트 분석에는 생성하지 않는다.
- 제거: 생성 모델에만 전달하던 비공개 우선순위 힌트, 이전 실습 중복 판정, 생성 결과의 근거 채점, 자동 보완 및 재생성. 이 조합은 기존 소규모 비교에서 일관된 품질 향상을 확인하지 못했다.
- 제거: 인용 사이의 빈 줄 구간만으로 추가 생성을 유발하던 실험. 기존의 인용 원문 일치 검사와 생성 모델의 근거 지침은 유지한다.

추천은 코드 탐색의 출발점이다. 코드의 정확성, 안전성, 전체 구현의 완전성이나 실습 생성 품질 향상을 인증하지 않는다. 자동 판정만으로 설명이나 채점 결과를 수정하지 않는다.

## 범위와 한도

기존 수집기에서 확보한 코드만 사용한다. 분기와 호출을 포함한 구간을 파일별로 추려 최대 36개를 확인한다. 12개씩 최대 3개 요청을 병렬 처리한다. 실행 로직 확률 0.75 이상, 역할 confidence 0.6 이상인 후보 중 최대 4개를 표시하며 같은 파일과 역할을 반복하지 않는다. 수치는 초기 선택 기준으로 일반적 정확도를 의미하지 않는다. 적절한 후보가 없으면 추천 영역을 표시하지 않는다.

TypeSafe에는 후보 코드, 경로와 프로젝트 요약만 보낸다. 화면 이미지, 계정 정보, 학습자의 답변이나 개인 메모는 보내지 않는다. 모델은 저장소를 실행하지 않는다. 질문 생성과 평가는 기존 OpenAI 모델이 담당한다.

## 설정

- `TYPESAFE_API_KEY`: 서버 전용. 로컬 `.env.local` 또는 Vercel Production에 등록한다.
- `TYPESAFE_MODEL`: 기본 `jev-1.13.0`.
- `TYPESAFE_ENABLED=false`: 새 Jev 호출을 중단하고 추천 없이 기존 분석을 제공한다. 이미 저장된 추천은 계속 표시한다. Vercel 환경변수 변경은 새 배포에 적용된다.
- 공식 API만 호출하며 요청당 6초, 70,000바이트 한도와 요청 취소를 적용한다. 실패 시 재시도하지 않고 해당 추천을 생략한다.
- 공급자 응답의 자료형과 확률 범위를 검사하고 요청하지 않은 답변은 버린다. 로그에는 지연 시간, 토큰 수와 상태만 남긴다.

## 저장과 이용 한도

추천은 분석 결과의 선택 필드 `codeGuide`로 저장한다. 기록 조회, 화면 이동과 백업 복원에서 재생성하지 않는다. 완료된 분석의 JSON 백업에도 포함되며 추천이 없는 이전 기록과 호환된다. 기존 프로젝트 분석 요청 안에서 실행하므로 사용자 분석 한도를 별도로 차감하지 않지만 TypeSafe API 비용과 응답 대기 시간은 추가된다.

## 검증

`jev.test.ts`는 공급자 응답, 실패와 취소를 검증한다. `jev-code-guide.test.ts`는 원본 인용 유지, 불확실한 추천 제외와 호출 상한을 검증한다. `e2e/jev-code-guide.spec.ts`는 390px과 1280px에서 코드 펼치기, 원본 링크, 가로 넘침과 기록 재열기를 확인한다. 관련 프로젝트 분석과 백업 계약 검사도 수행한다. 실제 공개 코드 검토 자료는 Git 추적에서 제외된 로컬 산출물에 보관한다. 추천의 연동과 탐색 편의성을 확인하는 것이며 A/B 사용자 효과를 입증한 것은 아니다.
