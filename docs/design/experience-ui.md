# 화면별 이미지와 탐색 UI

## 기능과 적용 범위

홈의 기능 배너는 접기 없이 표시한다. 6개 기능을 이름으로 직접 선택할 수 있으며, 선택한 타입에 따라 첫 배너와 나머지 순서가 달라진다.

| 타입           | 먼저 표시하는 기능 |
| -------------- | ------------------ |
| 원리 입문      | 서비스 원리 배우기 |
| 코드 훈련      | AI 코드 이해 훈련  |
| 내 서비스 이해 | 내 프로젝트 점검   |
| 배포 전 점검   | 서비스 보안 점검   |

배너는 8초마다 전환하며, 포인터가 올라오거나 키보드로 접근하면 멈춘다. 시작/멈춤 버튼을 제공한다. 모션 줄이기 설정에서는 자동 전환하지 않는다. 타입을 바꾸면 해당 타입의 첫 기능부터 표시한다.

홈 추천 카드, 서비스 원리, 코드 이해, 프로젝트 점검, 보안 점검, 학습 기록, 프로필, 로그인과 안내 페이지에 주제별 그림을 적용한다. 분야별 문제 목록과 코드 편집기 구성은 유지한다. 기존 실습의 상황 그림과 조작 가이드도 유지한다.

- 주요 학습 메뉴: 버튼을 눌러 각 단계의 행동과 결과를 살펴본다. 실제 학습 진도를 바꾸는 조작은 아니다.
- 프로젝트 설명용 예시: 소유자와 다른 사용자를 선택해 서버가 반환해야 하는 결과를 비교한다. 실제 서버 요청이나 AI 평가를 실행하지 않는다.
- 보안 점검: 전체, 보완 검토, 추가 확인, 설정 관찰로 결과를 필터링한다. 파일 내보내기에는 필터와 관계없이 모든 결과를 포함한다.
- 확인 메모: 텍스트를 작성한 항목 수를 표시한다. 검증 완료나 서비스의 안전성을 의미하지 않는다.
- 검토 방식과 개인정보 안내: 주요 내용으로 이동하는 바로가기를 제공하며 원문을 유지한다.

## 이미지 제작

기본 제공 `image_gen`으로 5종을 각각 생성했다. [프롬프트와 파일 목록](experience-visuals.json)에 입력한 전체 프롬프트를 보관한다. 생성된 그림은 실제 서비스 화면이나 검증 결과가 아닌 설명용 장식이다. 제목과 기능 설명은 HTML 텍스트로 제공하며 그림에는 빈 대체 텍스트를 사용한다.

| 경로                                       | 용도                       |         크기 |
| ------------------------------------------ | -------------------------- | -----------: |
| `public/images/experience/principles.webp` | 화면, 서버와 저장소의 연결 | 20,488바이트 |
| `public/images/experience/code.webp`       | 코드 실행과 결과 비교      | 29,684바이트 |
| `public/images/experience/project.webp`    | 프로젝트 설계 이해         | 34,146바이트 |
| `public/images/experience/security.webp`   | 공개 설정과 접근 권한 점검 | 79,562바이트 |
| `public/images/experience/progress.webp`   | 학습 기록과 이어하기       | 24,472바이트 |

원본 PNG를 유지하고 960×640 WebP로 변환했다. 이미지 크기를 예약하며 첫 화면 외의 그림은 지연 로딩한다. 모든 기능 설명과 버튼은 이미지 로딩에 의존하지 않는다.

## 재현 가능한 검증

`e2e/experience-ui.spec.ts`는 타입별 배너 우선순위, 좁은 화면에서의 이미지 로딩과 넘침, 단계 버튼의 키보드 조작, 설명용 접근 권한 예시, 보안 결과 필터와 전체 내보내기, 메모 복원을 확인한다. 해당 검증은 로컬 테스트 계정과 고정 응답을 사용하며 외부 서비스의 실제 보안 상태나 AI 질문 품질을 평가하지 않는다.

기존 배너, 학습 진입, 타입 선택, 프로필 저장과 보안 기록 테스트도 변경의 영향을 확인하는 데 사용한다. 화면 캡처는 Git에서 제외된 `artifacts/experience/`와 기존 테스트의 `artifacts/` 경로에 저장한다.
